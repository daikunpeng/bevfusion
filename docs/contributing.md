# Contributing

Thanks for your interest in contributing to BEVFusion!

## Development setup

1. Create a Python 3.8 environment
2. Install dependencies required by the repository
3. Install the project in editable mode:

```bash
python setup.py develop
```

## Coding guidelines

- Follow existing code style and formatting
- Prefer descriptive names and clear control flow
- Add concise docstrings for public functions/classes

## Documentation

- Add or update docstrings where APIs change
- Update `docs/` pages and examples when behavior changes

## Reporting issues

- Include environment, config, steps to reproduce, and logs
